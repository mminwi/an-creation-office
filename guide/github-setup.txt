AN Creation: setting up GitHub for a beginner. Revision 1 — October 11, 2026.
Read this when the inventor chose GitHub as the home (sop-office.txt, THE FOLDER), or wants a cloud analyst (Claude Code on the web, Codex, or Cursor) that needs GitHub. Then leave it.

ASSUME THEY HAVE NEVER USED IT
Most inventors have never seen GitHub. Go one step at a time, one question at a time, and say what each step is for in a line. Use the real words once, then use them: a repository (repo) is the project's online folder; a commit is a saved checkpoint; private means only they and people they invite can see it. They can do every step from their phone's web browser. If it gets frustrating, offer Google Drive instead, plainly: "We can keep it in Google Drive instead; it works just as well for this."

STEPS
1. Account. They make it themselves at https://github.com/signup (you can't make accounts for anyone). Free is fine. They pick a username, give an email, and set a password; GitHub emails a code to confirm. Never ask for or type their password.
2. Two-step sign-in. GitHub will ask them to turn on two-factor authentication. Suggest the GitHub Mobile app or an authenticator app, and to save the recovery codes somewhere safe (not in the project).
3. Connect GitHub in your app. In Grok Bot: the connectors (plugins), GitHub, sign in, allow. If it asks which repositories to allow, choose "All repositories", or come back after step 4 and add an-creation.
4. Make the repository. Try to create it yourself through the connector: name an-creation, Private, with a README. If you can't, walk them through it: https://github.com/new , Repository name: an-creation, choose Private, tick "Add a README file", Create repository.
5. Check it's private. The repository page shows "Private" next to the name. If it says Public, stop and fix it first: Settings, scroll to Danger Zone, Change visibility, Private.
6. Prove you can use it: write a small test file, read it back, delete it (each is a commit). Then record "Home: GitHub <username>/an-creation" in AN-Creation/office.txt and carry on with setup.

A CLOUD ANALYST (only if they want one)
Claude Code on the web (claude.ai/code), Codex (in ChatGPT), and Cursor's cloud agents can work on the repository from the cloud. Each needs that company's paid plan. They sign in to that service, choose "connect GitHub", and allow it access to an-creation. Record the choice in PROJECT.txt. Until then, you do the analyst runs yourself.

TROUBLESHOOTING (what usually goes wrong)
- No confirmation email: check spam and promotions; ask GitHub to resend; make sure the email was typed right.
- Locked out by two-step sign-in: use a saved recovery code; otherwise GitHub's recovery page https://github.com/login/two_factor/recovery . You can't get them back in; say so kindly and point them there.
- The connector says it can't see the repository: the app was allowed only some repositories. GitHub: Settings, Applications (Installed GitHub Apps), the app, Configure, add an-creation.
- "Repository not found" or a 404: the name or owner is off, or they're signed in to a different account. Check the exact username/an-creation.
- You can't create the repository or write files: the connector may be read-only. Have them make the repository by hand (step 4); if you still can't write, say so plainly and suggest Google Drive.
- A file is too big: GitHub refuses single files over 100 MB and warns over 50 MB. Keep big CAD, video and image files in Google Drive in a dated folder and put the link in the project.
- They made it Public by mistake: fix it right away (step 5). If anything sensitive was in it while public, tell them plainly and suggest talking to their patent attorney if the invention was described.
- They want to quit GitHub: fine. Copy the files into AN-Creation in Google Drive, prove you can write there, update office.txt, and carry on.

NEVER
Never type a password, code or key for them. Never make the repository public. Never put passwords, keys, an SSN, or bank or card numbers in any file or commit message.
