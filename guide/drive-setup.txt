AN Creation: Google Drive setup. Revision 1 — October 14, 2026.
Read this at setup, and whenever saving to Google Drive isn't working. Then leave it. Google Drive is the default home for project files. GitHub is an optional add-on for offices or people who write code (https://ancreationoffice.com/github-setup.txt). The steps for starting, saving and handing off are the skills office-startup, office-save and office-handoff. After setup, run office-setup-check.

WORDS, ONCE
The project folder is one Google Drive folder named AN-Creation. A saved checkpoint is a file written to that folder and read back. Never ask for or type a password; the owner signs in themselves.

ONE STEP AT A TIME (with the owner)
1. Connect Google Drive. If you don't have the Google Drive connector yet, set it up yourself and give the owner the sign-in link; they sign in with their own Google account. Then ask: "Done?" Check it worked: search Drive for anything (for example the title AN-Creation). If the search fails, the connector isn't on yet; ask them to try again.
2. Look first. Search Drive for a folder titled AN-Creation that the owner owns. If there is one, use it: never make a second. A re-made office carries on from its files.
3. If there is none, create it: a folder titled AN-Creation in My Drive. Inside it, create the same layout every office uses (https://ancreationoffice.com/project-folders.txt):
   team.csv (from https://ancreationoffice.com/template-team.csv)
   handoffs/ with for-<your role>.txt
   sops/ with library.txt and VERSION
   your office folder (for example Plastic Design/) with office.txt, plan.md, actions.csv, record/
4. Library. Download https://ancreationoffice.com/library.txt to your own working copy (/workspace/offices/<your role>/sops/library.txt) and upload it to AN-Creation/sops/ with your file-upload tool. Write VERSION beside it: "Library version: <line 1 of library.txt>" and "SOP updates: ask". The file is about 2 MB, so always read it from your working copy, one section at a time.
5. Prove a save: create AN-Creation/<your office>/record/setup-check.txt with today's date, read it back, and check it matches. Then move it to the trash. A connected app is not proof; the read-back is.
6. Write it down. In your office.txt: "Home: Google Drive AN-Creation", the folder IDs you use most (AN-Creation, handoffs, sops, your office folder), "Office version seen" and "Last saved". Add your row to team.csv.
7. Run office-setup-check and tell the owner pass or fail.

SAVING ON DRIVE (the rule office-save carries out)
- Write in place: a working file (office.txt, plan.md, actions.csv, team.csv, a hand-off inbox, Status, Plan) keeps its name and folder. Read it fresh just before you change it, so you don't write over another office's change.
- Keep a dated copy before a major change (a rewritten plan, a released revision, anything hard to redo): copy the file into the same folder's History/ as "<name> YYMMDD-HHMM" first.
- Drive search can miss a file made minutes ago. After a write, use the file ID it returned; never make a second copy because a search came back empty.
- Read back after every write and check it matches. Never call it saved when the read-back failed.
- Records and outputs are never edited once saved; a change is a new dated file.
- Quiet when it works. A failed save is one plain line to the owner.

WHEN IT FAILS
- Search or write fails: the connector is off or signed out. Reconnect the Google Drive connector yourself and have the owner sign in again. Don't start any other sign-in.
- Two files with the same name in one folder: keep the newest, merge any lines missing from the other, then trash the other. Say so in a line.
- A file over about 50 MB: keep it where it is and record where it lives.

GROK BUILD (heavy work)
The grok command runs in your own Shell on the shared computer, in a work folder /workspace/offices/<your role>/work/<job>. Copy in the files the job needs, run it, then save the results to Drive with office-save. grok, claude and codex are already installed and signed in; never install, sign in or turn on billing.

NEVER
Never type a password or code. Never share the AN-Creation folder publicly or with "anyone with the link". Never put passwords, keys, an SSN, or bank or card numbers in a file. Never turn on billing for them.

Sources: Google Drive help https://support.google.com/drive ; version history https://support.google.com/drive/answer/2409045 .
