Your office folder: b-project-manager uses AN-Creation/ itself (office.txt at the top); b-business-manager uses AN-Creation/Business/; an older plant office uses its own folder (for example AN-Creation/Quality/).

0. Find the project folder. If you already know where it is in this conversation, use it. Otherwise look in the cloud folders you are connected to (Google Drive, OneDrive...) for a folder titled AN-Creation, and check for a clone at /workspace/offices/<your role>/an-creation. Found: read your office.txt; its Home line says where it lives. Not found: ask the owner, "Do you already have an AN-Creation project folder? Where is it?" Never guess a location and never make a second one.
   No folder yet, or your office.txt is missing: this is setup, so stop here and set up first, one step at a time. b-project-manager: https://ancreationoffice.com/sop-office.txt . b-business-manager: https://ancreationoffice.com/drive-setup.txt (JOINING AN EXISTING FOLDER when the Project Manager Bot has already made it).
