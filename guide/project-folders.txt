AN Creation project folders. Revision 16 — October 18, 2026. Human explanation: https://ancreationoffice.com/project-folders.html

One person talks to the system: a solo inventor or entrepreneur. Partners may be involved, but their input comes through that person. One folder holds everything, with one folder per invention inside it. Each invention has two sides: Your files (the person's) and Office files (the assistants'). Built like a Unix system: files and folders do the work. A queue is a folder of ticket files.

Only the project lives here, plus the procedures: sops/, one file per installed version, each bot on its own until the owner tells it to update (version.txt UPDATING). The bots read their procedures from it, not from the website. A template copied in to be filled out (a form, the plan) is a project file from then on: dated, and never overwritten by a newer template.

Source of truth: Office files plan.md, forms/ and record/. Your files are produced from them, so they can be rebuilt at any time. Nothing you change or delete there is lost.

Dated folders. Nothing made for you is written over. Each analyst run works in its own dated folder and leaves it as it was. Each page, picture, render, drawing and timeline goes in its own dated folder; an update is a new folder. Before Status or Plan is regenerated, the old copy goes to History/. It uses more space, and it means you can always go back and look.

Your format. At setup b-project-manager asks whether you want plain pages (Markdown, readable on a phone) or Word and Excel files you download. Your files use that format. Office files use whatever suits the assistants. PDF only for things sent out or kept as issued. You can change your mind; the files are regenerated.

The record, two ways. Office files keep everything as received, including full meeting and conversation transcripts. Your files keep the same dated events in readable form: the email, the document, and a typed-up summary of each meeting or conversation instead of the transcript.

Your edits. You may edit your forms, plan or spreadsheets in your own program. At the next conversation b-project-manager notices the changes and checks them with you in a line or two before the master copies change.

Send to the office. Anything dropped there is filed into the record and then cleared. Identical content to something already filed is a duplicate: note where the first copy is, no new task. Changed content is a new version: keep both and check any changed numbers.

The queue. A ticket is a file. Its folder is its status: open, active, done. revisit/ holds "for now" answers named by the date to ask again (261013-company.txt). On that date the file moves to open/.

Analyst runs. Each run works in its own dated folder, writes DONE.txt when it finishes, and is never renamed. Finished runs older than a month move to archive/.

Several inventions. Each has its own folder, plan and queue. One b-project-manager runs them all (inventions are folders, not bots; https://ancreationoffice.com/sop-team.txt); it names the invention it's on and files each conversation in that invention's record. Starting a parked idea: set up its folder, PROJECT.txt, intake form and first ticket before saying it has started; add it to All inventions; mark the idea started in ideas.txt. Answers never cross between inventions. A fact that applies to two, such as your company, is recorded in each, with its source.

Where it lives. One private folder named AN-Creation, wherever the owner wants it, with this layout inside (https://ancreationoffice.com/drive-setup.txt). A cloud folder (Google Drive, OneDrive, Dropbox) is recommended: it works from a phone, keeps earlier versions, and survives a lost computer. Google Drive is the default when they have no preference. Each office keeps a working copy of the library at /workspace/offices/<role>/sops/library.txt. office-save proves a write by reading it back. For offices or people who write code, the same AN-Creation/ can live in a private GitHub repository named an-creation instead, with one clone per office at /workspace/offices/<role>/an-creation (https://ancreationoffice.com/github-setup.txt). office.txt says which: "Home: Google Drive AN-Creation" or "Home: GitHub <username>/an-creation". No Home: line: GitHub if /workspace/offices/<role>/an-creation is a git clone, otherwise Google Drive.

Backups. Records and outputs are never edited once saved (a change is a new dated file or folder); working files like plan.md and Status are updated in place. Cloud folders like Google Drive and OneDrive keep earlier versions of each file for a while (a plain folder does not, so History/ and the owner's own backup matter more), and a dated copy goes to History/ before any major change (on GitHub, every commit is kept). Going back to an earlier version is a normal part of working with AI. See https://ancreationoffice.com/version-control.txt

Template. https://ancreationoffice.com/plan-template.txt contains a blank plan. Do not replace an existing plan with a blank one.
