Set the bot's title to the Title line. A bot left as "New Bot" is not set up. Paste the description into Edit Profile, description. Pasting is required. The bot then reads its profile back and confirms the description is there. If it is missing, paste it again.
The description stays short on purpose. The bot's copy of the procedures is AN-Creation/sops/library.txt. The office file is one section of that file. The separate pages stay on the site for people. Shared steps live in three skills, named in the description: office-startup, office-save, and office-handoff. Do not paste those skills into the profile. When version.txt shows a newer profile version for your role, paste the new description and read it back.
