HOW TO USE THIS (every bot)
Follow the office-startup skill. This file is the office rule that skill carries out. Do not keep a second copy of the skill's steps here.

One shared library: AN-Creation/sops/library.txt in the project folder (wherever office.txt's Home line says; the an-creation repository for GitHub offices), one copy and one version for every office. Each office reads its working copy (/workspace/offices/<your role>/sops/library.txt on folder offices, the clone on GitHub offices). Read the one procedure you need from that file.

LINKS ARE SECTIONS
A link such as https://ancreationoffice.com/sop-cost-sheet.txt in a procedure names a section of library.txt: the lines after === FILE: sop-cost-sheet.txt ===. Read it there, not on the website. Open the website only at first setup, when the owner asks to update, or when a section is missing from library.txt (say so in a line). The separate pages stay on the site for people.

The bot's copy is library.txt plus VERSION. https://ancreationoffice.com/sops-manifest.txt is the list the bundle is built from (Office version on the first line, then one path per line), including the resource library: resources.json, resources.txt, planning-resources.*, resource-crosscheck.*, sop-resource-map.txt, and every resources-*.html shelf. library.txt has the same version on its first line, then every one of those files in full, each after a line `=== FILE: <path> ===`. The file is about 2 MB. Read one section by its marker. The way to pull a section is in version-control.txt.

UPDATING (only when the owner asks)
The bots never update on their own and never check the website for a newer version unless asked. The owner decides when. The ask is anything like "update", "update yourself", "check for updates", "is there a new version?".
1. Open https://ancreationoffice.com/version.txt?t=<today's date> and compare its "Office version:" with line 1 of library.txt.
2. Same: say so in a line ("You're up to date: 261018.17.") and stop.
3. Newer: tell the owner in a few lines what is new, from the CHANGES entries after their version. If they asked to update, that is the yes: go on. If they only asked whether there is one, ask "Want me to update?" and wait.
4. Download https://ancreationoffice.com/library.txt once, save it over AN-Creation/sops/library.txt and rewrite VERSION beside it ("Library version: <line 1>", "Updates: only when the owner asks"), with office-save, and read both back. On GitHub it is one commit (never force-push main).
5. Re-read your office file from the new library.txt, write the new number on "Office version seen", and if your profile version below is newer than your profile, set the new description (see below).
6. Say it is done in one line. The other bot picks up the new library at its next conversation (office-startup step 2); it does not need its own update.
If the site does not open, say so and carry on with the library you have.
An older VERSION file may still have an "SOP updates" line (auto, ask or pinned). It is no longer used: updates happen only when the owner asks. Replace it at the next update.

The only place a bot records a version it has seen is the "Office version seen" line in its office.txt. That line is this file's "Office version:" value, format YYMMDD.N, not a file revision. Project Manager Bot: AN-Creation/office.txt. Office Manager Bot: AN-Creation/Business/office.txt. Every other office: office.txt in that office's folder. Do not write version-seen.txt, and do not put that line in business.txt. If AN-Creation/Business/version-seen.txt still exists, copy its number into AN-Creation/Business/office.txt once when that line is empty, then delete version-seen.txt.

When the library you are using is newer than "Office version seen" (the owner had it updated), re-read your office file from library.txt, tell the owner in one line what changed, and write the new Office version on that line.

If your profile version here is newer than your profile, set your own description from the short block in profile.txt and your title, with your profile tool (fallback: the owner pastes it). Read the profile back. Then run office-setup-check.

"What version are you on?": the Office version you are working from (line 1 of library.txt), and your profile version. Don't check the website unless they ask about updates.
