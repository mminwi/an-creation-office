HOW TO USE THIS (every bot)
Follow the office-startup skill. This file is the office rule that skill carries out. Do not keep a second copy of the skill's steps here.

Each bot stays on its own version. AN-Creation/sops/ keeps every version ever installed, one file each, never written over: library-<version>.txt (for example library-261018.29.txt). library.txt is a copy of the newest one, for older setups. A bot's office.txt says which version it works from ("Office version seen"), and the bot reads that version's file through its working copy (/workspace/offices/<your bot id>/sops/, or the clone on GitHub offices), one section at a time. One bot updating never changes another bot: each moves only when the owner tells that bot to update. A bot you know is better than a new bot you don't.

A link such as https://ancreationoffice.com/sop-cost-sheet.txt in a procedure names a section of library.txt: the lines after === FILE: sop-cost-sheet.txt ===. Read it there, not on the website. UPDATING (only when the owner asks, one bot at a time)
The bots never update on their own and never check the website for a newer version unless asked. The owner decides when, and for which bot. The ask is anything like "update", "update yourself", "check for updates", "is there a new version?". It moves only the bot that was asked.
1. Look for a newer version in two places: AN-Creation/sops/ (another bot may already have installed one) and https://ancreationoffice.com/version.txt?t=<today's date>. Compare each with your "Office version seen".
2. Nothing newer: say so in a line ("You're up to date: 261018.29.") and stop.
3. Newer: tell the owner in a few lines what is new, from the CHANGES entries after your version, and where it is (already in the folder, or on the website). If they asked to update, that is the yes: go on. If they only asked whether there is one, ask "Want me to update?" and wait.
4. Already in the folder: use that file. Only on the website: download https://ancreationoffice.com/library.txt once and save it as AN-Creation/sops/library-<version>.txt (the version is its line 1), and also over AN-Creation/sops/library.txt; rewrite VERSION ("Newest version in this folder: <version>", "Updates: only when the owner asks, one bot at a time"); save with office-save and read back. On GitHub it is one commit (never force-push main).
5. Copy that version to your working copy, re-read your office file from it, write the new number on "Office version seen", and if your profile version below is newer than your profile, set the new description (see below).
6. Say it is done in one line. Other bots stay where they are; each mentions the newer version once and waits to be asked.
If the site does not open, say so and carry on with the version you have.
An older VERSION file may still have an "SOP updates" line (auto, ask or pinned). It is no longer used. Replace it at the next update. An older folder may have only library.txt: at the next update, save its version as library-<version>.txt first, so nothing is lost.
