AN Creation backups and version control. Revision 7 — October 14, 2026. Human page: https://ancreationoffice.com/version-control.html
Google Drive is the default home again (Office version 261014.2). GitHub stays a full, supported option for offices or people who write code; offices already on GitHub keep working as written under IF THIS OFFICE USES GITHUB.

WHY
AI is new, and it goofs up: a file gets overwritten, two versions get mixed, a chat gets cleared, a bot gets deleted. In practice, going back to an earlier version is close to a daily event. So the office never depends on one copy of anything, and never on the chat.

HOW IT'S KEPT
- The project is one private Google Drive folder, AN-Creation (https://ancreationoffice.com/drive-setup.txt). office.txt says "Home: Google Drive AN-Creation". If it says "Home: GitHub", follow IF THIS OFFICE USES GITHUB below instead. No Home: line yet (offices set up before 261014.2): GitHub if /workspace/offices/<role>/an-creation is a git clone, otherwise Google Drive; write the Home: line at the next save.
- The shared procedure library is AN-Creation/sops/library.txt plus AN-Creation/sops/VERSION. One version for every office. library.txt is about 2 MB. Its first line is the Office version. Each file follows after a marker line `=== FILE: <path> ===`, including the resource library. Each office reads it from its working copy, /workspace/offices/<role>/sops/library.txt (downloaded from the Drive folder, or from https://ancreationoffice.com/library.txt), one section at a time: awk '$0=="=== FILE: standing.txt ==="{p=1;next} /^=== FILE: /{p=0} p' library.txt. A refresh downloads https://ancreationoffice.com/library.txt once, uploads it over AN-Creation/sops/library.txt and rewrites VERSION beside it. The rule is https://ancreationoffice.com/version.txt
- Two kinds of files (D-029). Working files are updated in place: office.txt, business.txt, plan.md, actions.csv, team.csv, the hand-off inboxes, Status and Plan. Before a major change to one, a dated copy goes to History/ ("<name> YYMMDD-HHMM"). Records and outputs are never edited once saved: documents, drawings, pages, analyst runs, record/ entries, released revisions. A change is a new dated file.
- The record. Every conversation and every analyst run is saved in record/ and sessions/. Anything not yet saved is only in the chat.
Say it to the owner once, in a line: "Your work is saved to your Google Drive as we go, and I keep a dated copy before any big change."

SAVING (every office and b-analyst)
Follow the office-save skill. This is the office rule it carries out.
- Read a working file fresh just before you change it, then write it in place (same name, same folder).
- Before a major change, keep a dated copy in History/.
- After every write, read the file back and check it matches. A write you did not read back is not confirmed.
- Quiet when it works. A failed save is one plain line to the owner. Never call it saved when the read-back failed.
- End of a conversation: one "Last saved" line in your office.txt (time, what).
- Files over about 50 MB: leave them where they are and record where the original lives.
Setup: https://ancreationoffice.com/drive-setup.txt

IF THIS OFFICE USES GITHUB (code offices, and offices already set up on GitHub)
- Your own clone: /workspace/offices/<your role>/an-creation. Never a shared clone, and never /workspace/repo. The GitHub connector is read-only; saving is git and gh in your Shell.
- One commit per turn. pull --rebase before the commit; if the push is rejected, pull --rebase and push again. After the push, read the file back with gh. Unpushed work is not saved.
- Never force-push main. A work branch is named by role (b-project-manager/<topic>) and deleted after it merges.
- The library is AN-Creation/sops/library.txt in the repository; a refresh is one download and one commit.
- "Last saved" includes the commit. Files over about 50 MB stay out of the repository.
Setup: https://ancreationoffice.com/github-setup.txt

IF SOMETHING GOES WRONG
- A file got overwritten, mixed up or deleted: look at the earlier dated files and History/ first, then the file's version history in Google Drive (or on GitHub), find the last good version, restore it as a new save, and say what was restored.
- A chat got cleared, or a bot was deleted and made again: everything that was saved is still there. The new bot looks for the AN-Creation folder first, reads office.txt (its "Last saved" line), All inventions, PROJECT.txt, plan.md and the latest status, and carries on from the last saved checkpoint. Anything said after the last save was only in the old chat: ask the owner about it.
- They lost their phone: sign in to Google (and GitHub, if used) and their AI app on the new one. The project is in the cloud.

NEVER
- Never share the AN-Creation folder publicly or with "anyone with the link". Never make a GitHub repository public.
- Never put passwords, keys, an SSN, or bank or card numbers in any project file, issue or commit message.
- A saved version is not an approval. History does not replace the revision and change records (sop-change-control.txt) or the record of what was sent to whom.
- Big CAD, video and image files (over about 50 MB): record where they are.
