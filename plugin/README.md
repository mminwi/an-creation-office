# AN Creation Office (plugin), version 261018.45

40 skills for the AN Creation bots: the Project Manager Bot (`an-project-manager`), the Office Manager Bot (`an-office-manager`) and the Bot Tester (`an-tester`). Start with `an-office`: how the office works as skills, where the files live, and an index of every procedure.
Built from https://ancreationoffice.com by scripts/build-plugin.py; the website pages are for people.
