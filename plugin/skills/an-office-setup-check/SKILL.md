# Setup check
1. Write `setup-check.txt` with today's date and time in your office folder on this computer. Read it back. Pass only if it matches.
2. If there is a Drive copy: upload it with UploadFile to the Drive AN-Creation folder, download it back with DownloadFile by its file ID, and compare.
3. Remove the test file on this computer, and in Drive send it to the trash with `trash_file` by its file ID. If the trash fails, tell the owner once they can delete `setup-check.txt` there.
4. Say pass or fail in one line, and which step failed.
