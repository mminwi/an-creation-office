# Calling the analyst

When: a ticket's form is confirmed; fewer than three paths are open (`an-analyst` (You are b-analyst for an AN Creation invention project)); something new arrived in Send to the office or the owner changed their files. Nothing they send waits more than one conversation.

Before: save this conversation so far into the invention's `Office files/record/YYMMDD-NN-M-project-manager-conversation/transcript.txt` (`an-office-save`). The ticket holds everything the run needs; fix it first if not.

The run (default: your own run, as its own step; Grok Build isn't installed on this computer):
1. Tell the owner in one line that you're doing the heavy work now.
2. Make `/workspace/AN-Creation-work/<your bot id>/YYMMDD-HHMM-<ticket>/` and copy in the ticket and the files it names.
3. Follow `an-analyst` as b-analyst, in that folder: write your notes, the results and DONE.txt there.
4. Put the results back with `an-office-save`: the run folder into `Office files/sessions/YYMMDD-HHMM-slug/` (DONE.txt last), each file the ticket updates in its place, each read back.
5. Come back as yourself.
Another analyst the owner set up (named in PROJECT.txt): start it the way PROJECT.txt says, with one line, and do steps 4 and 5 when it's done.

Check it came back: every file the ticket expects is there and reads back, DONE.txt says who ran it, the next ticket has its parts. Missing: run once more for what's missing; still missing: tell the owner it's taking longer, note it in plan.md, stop. Never fill a gap with a guess.

After: say in a line or two what was found and what's next, then ask the next single question.
